# wwwdaldo

Dépôt des sources du site

## Feuille de style
Le site utilise SASS pour un style modulaire et maintenable, avec la compilation gérée par esbuild pour une performance optimale.

## JavaScript
Le framework Preact est utilisé pour une version allégée de React, permettant des interfaces utilisateur performantes et réactives, tout en réduisant la taille du bundle.
